# 需求调研

## 提问规则

先提取，再补问。已有大纲可以说明主题和章节，但通常不能可靠推断目标、听众及演讲时长。入口③的源 PPTX 可以说明现有页数、页序和部分内容，但不能可靠推断新的目标、听众和修改范围。
把字段标为“用户明确 / 材料提取 / 默认 / AI 建议 / 待补充”，不要把猜测当成用户要求。

| 字段 | 要求 | 选项或默认值 |
|---|---|---|
| 主题 | 必填 | 无默认值 |
| 使用场景 | 必填，有默认值 | 方案汇报（默认）、工作汇报、客户交流、演讲、培训、其他 |
| 具体场景 | 选填，用于路由推荐 | 述职竞聘 / 开题答辩 / 教学说课 / 党政党课 / 数据可视化 / 总结复盘 / 运营汇报 / 商务提案 / 架构流程 / 其他；命中后的处理见 SKILL.md §四 |
| 制作路线 | 必填，无通用默认值（仅 PPTX） | 套公司模板 / 用现成设计模板 / 从零设计；问法与落点见 SKILL.md §四「制作路线判定」 |
| 公司模板 | 仅“套公司模板”时必填 | 模板名称或路径；来源判断见 SKILL.md §四「公司模板」 |
| 视觉密度 | 选填，有默认值 | 专业简洁（默认）/ 复杂豪华；制作路线为 C 时由所选模板或模式决定 |
| 输出格式 | 必选，有默认值 | 可编辑 PPTX（默认）/ HTML / 同时交付（仅用户明确要求时）；要发给别人继续改、走公司流转 → 可编辑 PPTX；现场放映、线上分享、想要动效 → 网页 HTML（不能在 PowerPoint 里编辑）；套公司模板固定 PPTX |
| 视觉风格与配色 | 按需提取或补问 | 与视觉密度分开记录；HTML 据此判断 D/E；未指定配色时用所选制作 Skill 的默认主题，记录“按默认主题”，不硬编码编排层主色 |
| 演示语言 | 选填，有默认值 | 中文（默认，跟随用户）/ 英文 / 中英双语 / 其他；影响正文、标题、备注和成品文件命名 |
| 画布比例 | 选填，有默认值 | 16:9（默认）/ 4:3 / 其他；HTML 默认自适应 16:9，竖屏或特殊比例时记录 |
| 目标 | 必填 | 希望听众听完理解什么、认可什么、决定什么或采取什么行动 |
| 听众 | 必填 | 身份、关注点、主题熟悉程度；只补问影响策划的部分 |
| 时长 | 必填 | 正数，单位分钟；必要时明确是否包含问答 |
| 目标页数 | 选填 | 未指定则 AI 按内容、时长建议；明确总页数是否包含封面及章节页 |
| 背景及注意事项 | 选填 | 业务背景、必讲/禁讲内容、敏感信息、口径、日期、语言、品牌要求 |

“必填且有默认值”可以使用已展示的默认值；“必填、无默认值”（主题、目标、听众、时长、制作路线）必须来自用户或单独提问，不能编造。目标、听众、时长可以给推荐值（例如“按 20 分钟、面向通用业务听众、目标是让听众了解并认可方案”），用户确认后才算采用。缺口较多时用短表单，不逐字段追问；制作路线用一句话问，需要三选一时不展开成表单。无需逐字段确认；需求补齐后前台展示完整内容，一次确认后再保存。

## 入口③：修改/美化现有 PPTX

入口③复用主表的主题、目标、听众、时长、视觉风格、演示语言、画布比例等字段；不询问制作路线与视觉密度（沿用源设计），不展示 HTML 选项。专属字段见 [edit.md](edit.md)「需求字段」。

## 表单

信息很少时用最小表单（8 项）；用户想一次填全或信息已完整时用完整表单。已有信息先预填。

```text
主题：
希望达成的目标：
听众：
时长：__ 分钟
使用场景：方案汇报 / 工作汇报 / 客户交流 / 演讲 / 培训 / 其他（默认：方案汇报）
具体场景：述职竞聘 / 开题答辩 / 教学说课 / 党政党课 / 数据可视化 / 总结复盘 / 运营汇报 / 其他（可选，用于推荐模板）
做法：不确定就写“你定”，我会按场景推荐；也可直接选：公司模板 / 现成模板库（21 套中文成品模板）/ 从零设计
输出格式：可编辑 PPTX（默认）/ 网页 HTML / 两种都要；要发给别人继续改、走公司流转选 PPTX；现场放映、线上分享、想要动效选网页（不能在 PowerPoint 里编辑）
```

其余字段按默认值处理：视觉密度专业简洁、演示语言中文、画布比例 16:9、页数由 AI 建议；用户有特殊要求时再补问。

完整表单在最小表单之外增加：

```text
公司模板：模板名称或路径；如果是 .pptx/.potx 文件请注明“模板文件”（选公司模板时填）
视觉密度：专业简洁 / 复杂豪华（默认：专业简洁）
视觉风格与配色：有指定则填写；网页如希望杂志风或瑞士风请注明
演示语言：中文 / 英文 / 中英双语 / 其他（默认：中文）
画布比例：16:9 / 4:3 / 其他（默认：16:9）
目标页数：可留空，由 AI 建议
背景及注意事项：可留空
```

完整表单的“具体场景”另含商务提案、架构流程，不填则由 AI 从主题识别。

附加信息按需获取：

- 已有大纲制作：请用户提供粘贴文本或文件路径；支持的文件类型由当前读取工具决定。
- 需要事实、指标、案例时：询问现有材料和可引用来源；缺失的数据不得编造。
- HTML：记录用户关于风格的原话、明确指定的颜色和图片/截图要求，供路由判断并原样交接；需要补问杂志风/瑞士风时在调研阶段一并问（见 [production.md](production.md) 分支 E）。
- 目标时长与页数明显冲突时，解释节奏影响，提出推荐调整，请用户决定。

## 需求确认与落盘

按下方模板在对话中展示项目信息、已知需求和原始材料（包括来源、默认值、已知冲突和拟保存目录）；`## 执行记录` 在落盘时由 AI 自动写入，不在对话中展示。
入口③将需求表与 `修改方案_确认版.md` 一起展示，任务信息写在修改方案中，不在需求调研里重复。
先问“以上需求是否确认？确认后保存 `需求调研.md`，再进入{思路对齐/已有大纲检查/修改方案确认}”。入口②（大纲已齐备）或入口③若需求与逐页大纲/修改方案已一起完整展示并明确列名，可一次确认并同时保存。
用户直接给了完整需求也不代表已确认 AI 整理的未展示内容；已在前台展示并明确批准的同一版本可复用确认，无需重问。
默认值、推断及资料提取须在确认前就对用户可见。
快速模式按 [confirmation.md](confirmation.md)「快速模式」执行。
